# Aesthetic OS · 整体形象参考室

先用风格测试找到自己的风格倾向，再通过时尚杂志官网的真实造型案例，把穿搭、妆容、品牌文化与个人表达连接起来。

本仓库包含当前演示网站的完整静态源码，以及产品需求、两天开发计划、资料方法和案例知识库。

## 怎样运行

直接用 Edge、Chrome 或 Firefox 打开 `index.html`。不需要安装依赖，不需要 API Key。

如果已有 Python，也可以在本目录运行：

```sh
python -m http.server 8000
```

然后打开 http://localhost:8000 。

## 已有功能

- 五步风格测试：按量感、曲直、动静与氛围词计算八大风格倾向，并用色彩题估计四季色彩倾向。每题都可以选“不确定”，不需要照片。
- 风格报告：主风格与次风格、风格比例、三个维度、风格坐标图、色板，以及穿搭、妆容、发型方案、衣橱清单、7 天练习和对应的杂志真实参考。
- 博主图库：14 位小红书博主、301 套真实穿搭，按八种风格分组，每张图注明“穿搭出自 @博主”，点图打开小红书原帖；测试报告会列出与你主风格相同的博主，方便去关注、看视频学习。
- 浏览及筛选六个真实穿搭、妆容案例，查看对应杂志官网原文与图片署名。
- 区分原文事实、原创文化解读和普通人的日常借用方式。
- 切换巴黎世家、Yves Saint Laurent 与 Comme des Garçons 的文化背景。
- 测试最后一步选择场景、表达目标、新增预算、妆容时间与舒适需求，用来调整报告里的建议。
- 下载 JSON、清空本次选择、调用浏览器打印或存为 PDF。
- 第 2 步可选填三维，报告判断身材类型并给出版型建议；发型建议包含刘海、直发或卷发、发色。
- 答案和报告保存在本机浏览器，打开小红书再返回或刷新页面都不会丢失；不会上传。

## 图像与内容说明

博主图库的照片来自小红书博主的公开笔记封面，站长已私信取得展示授权；含其他人或儿童的照片没有收录。博主要求撤下时，在 `gallery-data.js` 删除对应条目并删掉图片文件即可。

杂志案例照片来自 Vogue、ELLE、Harper’s BAZAAR 官方文章及图片服务，采用远程引用，不包含下载的杂志照片或 AI 生成人物图。每条案例保留来源、年代和已知署名；未获得图片商业使用许可。图片需要联网，不能加载时请打开卡片的官网原文。

文化解读、气质表达与日常建议由 AI 辅助整理，仍待专业复核。图片中的模特不是产品用户，参考照片不代表本人试穿效果。

## 当前范围

这是有限案例与模板组成的交互原型，没有接入真实大模型、照片诊断、身体测量、付费或虚拟试衣。风格测试根据用户自己选择的外在特征计算倾向，是形象设计常用的描述工具，不是科学诊断，也不判断性格；八种风格的坐标与穿搭妆发建议为本项目整理，题目结构参考了小红书上常见的量感曲直与四季色彩自测，尚待专业复核。原先提供的 Python/FastAPI 与 React 工程仍需单独恢复与接入；本仓库不声称已实现那些未完成的后端计划。

案例检索于 2026-10-22 至 2026-10-23，所用系列为 2024–2025 年，不是实时趋势榜。2026-10-30 核验：两个脚本通过 `node --check`；在浏览器中用 8 组典型答案核对八种风格、5 组答案核对四季色彩，结果都符合预期；桌面（1280 宽）和手机（375 宽）下测试与报告均无横向滚动，控制台无报错；案例筛选和品牌切换照常工作。打印版式只调整了样式，未做打印预览核验。
